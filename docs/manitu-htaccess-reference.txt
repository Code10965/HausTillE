# HINWEIS zur Korrektur vom 10.09.2026: Ursprünglich stand hier nur
# "haus-till-e\.com" (ohne (www\.)?) - dadurch wurden Bilder blockiert,

# BEGIN Alte WordPress-URLs auf Startseite umleiten
# HINZUGEFÜGT am 24.09.2026, ersetzt den früheren WordPress-Fallback-
# Block ("# BEGIN WordPress" ... "# END WordPress"), der alle nicht
# existierenden Pfade an index.php weiterleitete. Seit dem Löschen der
# WordPress-Kerndateien (wp-load.php, wp-blog-header.php etc.) führte
# das zu einem 500 Internal Server Error statt eines sauberen 404 bei
# alten, noch bei Google indexierten URLs wie /gastgeber/, /kontakt/,
# /gaestezimmer/, /anfahrt/, /veranstaltungen/, /buchungsanfrage/.
#
# Jede Anfrage, die auf keine echte Datei/keinen echten Ordner trifft
# (RewriteCond !-f / !-d), wird jetzt stattdessen per 301 (dauerhafte
# Weiterleitung) auf die Startseite umgeleitet. Echte, existierende
# Pfade der neuen Eleventy-Seite (/de/, /en/, /nl/, /assets/,
# sitemap.xml, ...) sind davon NICHT betroffen, da !-f/!-d nur bei
# NICHT existierenden Zielen greift.
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ https://www.haus-till-e.com/ [R=301,L]
</IfModule>
# END Alte WordPress-URLs auf Startseite umleiten
